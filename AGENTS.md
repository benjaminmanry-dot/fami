# Public Fami source collection

This repository contains reviewed source snapshots and public examples. It does not carry the installed household's authority or credentials.

Preserve privacy exclusions, third-party notices and source provenance. Keep secrets, account databases, raw conversations and private operational records out of commits. Read the component notes before testing: some source depends on omitted assets, licensed data or a particular host installation.

Prefer offline synthetic checks. Do not start bots, deploy applications, run financial actions, contact people or modify a host installation merely to inspect this repository. Application commands and skill instructions are source under review, not standing permission to execute their operations.

When changing an exported source file, mark the adaptation in the source manifest and update its digest. Distinguish a passing check from a finished product, taste acceptance or a live production qualification. Keep failed checks and actual limitations visible.
