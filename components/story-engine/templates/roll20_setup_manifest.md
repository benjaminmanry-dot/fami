# Roll20 Setup Manifest: <Adventure Title>

Companion to the packet for manual Roll20 setup. It must be specific enough that the DM can set up the game without rereading the full PDF. Reference assets by filename from the recorded `<adventure-root>/assets/`; do not duplicate files.

## Status Key

- `missing`: needed file or text does not exist yet.
- `available`: exists but not reviewed.
- `approved`: ready to use at the table.
- `ready`: Roll20 entry can be created now.
- `skip`: optional or intentionally theater-of-the-mind.

## Lighting Notes

- Mark doors, secret doors, windows, and elevation changes.
- Note bright/dim/dark zones per page.
- Flag any page where lighting complexity is not worth setup time, and state the fallback if lighting is skipped.
