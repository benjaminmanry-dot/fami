# Salience Rubric

Use this before delivering Reddit outreach posts, public advice essays, and longer comments.

## Core Test

The post should leave a DM with a sharper way to think and a more useful way to act. If it only sounds good, revise it.

## Five Questions

1. What live DM pain point is this correcting?
2. What common advice, habit, or anxiety is being reframed?
3. What distinction can the reader use tomorrow?
4. What table example makes the distinction feel real?
5. What should a qualified reader want to say back?

## Outreach-Specific Test

For Reddit outreach, the post should create qualified conversation, not advertise.

Check that the draft:

- Serves the subreddit before it serves Ben.
- Gives real value before inviting response.
- Does not sound like a sales page disguised as advice.
- Does not over-explain Ben's credentials.
- Makes experienced DMs feel seen without alienating newer DMs.
- Opens a door for conversation by asking a useful question or naming a practical tension.

## Compellingness Pass

Raise salience by adding one of these:

- Stakes: what gets worse at the table if the advice is ignored?
- Friction: what makes the advice hard to apply?
- Specificity: what concrete table object, person, or moment carries the claim?
- Tradeoff: when does this advice fail or need adjustment?
- Portable language: what exact question or phrase can the DM use in prep?

## Red Flags

Revise if the post:

- Could be summarized as "be better at DMing."
- Has a strong title but no usable distinction.
- Uses a vivid example that does not change the advice.
- Feels like it is trying to win Reddit instead of help DMs.
- Ends with inspiration instead of judgment, permission, or a useful question.
