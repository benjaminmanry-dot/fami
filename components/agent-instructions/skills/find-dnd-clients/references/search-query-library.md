# Search Query Library

## High-intent public queries

Adapt the date, location, system, and platform syntax:

- `"looking for a DM" D&D adult paid`
- `"looking for a DM" D&D group`
- `"need a dungeon master" adult group`
- `"need a dungeon master" D&D online`
- `"hire a DM" D&D online`
- `"paid DM" "looking for" players`
- `"group needs a DM" D&D 5e`
- `"DM ghosted" D&D group`
- `"forever DM" "looking for a game" adult`
- `site:reddit.com/r/lfg "looking for DM" paid`
- `site:dndbeyond.com/forums "looking for a DM"`
- `D&D birthday professional dungeon master adult`
- `D&D parent "looking for a DM"`
- `D&D "legal guardian" dungeon master`
- `D&D team building dungeon master`

Run at least one broad query without age terms so unknown-age signals remain visible. Use negative terms such as `-youth -kids -teen -free-only` only after that broad pass when they materially improve precision; they can hide guardian-managed opportunities. Never use query filtering as a substitute for reading the actual post and age evidence.

## Query ledger

For every batch, record:

- exact query;
- source or search engine;
- run time and timezone;
- result pages checked;
- number of opportunities reviewed and retained;
- repeated false positives; and
- the next narrower query, if any.

Bound research by commissioned coverage, expected value and remaining resources. A larger list is not automatically better research; ten retained records is not a universal stop.
