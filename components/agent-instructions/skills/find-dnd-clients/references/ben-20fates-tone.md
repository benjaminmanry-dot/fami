# Ben / 20Fates Tone

Use a grounded, specific, table-aware voice. It should not sound like a funnel. Talk about the actual experience of play: choices, consequences, trust, rhythm, and the kind of table someone is entering.

For outreach:

- start with the prospect's stated need, not Ben's brand;
- name one real fit point from the post;
- say paid plainly and early;
- use 20Fates as proof of seriousness, not as a billboard;
- prefer “see if there's a fit” over “book a consultation”; and
- make it easy to say no or say they already found someone.

Useful phrases include “The part that caught my eye was…,” “If paid is still what you have in mind…,” and “No worries if you have already found someone.”

Avoid hype, generic claims, manufactured scarcity, a long credential preamble, funnel vocabulary, and polished paragraphs that could be sent to anyone.

Use website facts only from a fresh offer cache. The current funnel lets the person choose how to talk with Ben; do not turn every invitation into a voice-call booking request.
