# Campaign Management

Use this for ongoing campaign workspaces. Standalone one-shots and bounded adventure products belong to Story Engine.

## Workspace Rule

Keep each campaign in its established project or campaign root. When no convention exists, use a clear lowercase slug under `campaigns/<campaign-slug>/`. Do not mix unrelated campaigns.

Create only files the campaign needs. A mature campaign commonly has:

- `campaign.md`
- `canon.md`
- `party.md`
- `npcs.md`
- `factions.md`
- `locations.md`
- `threads.md`
- `sessions/`
- `prep/`

For a pre-session-one campaign, use the user's brief as approved starter canon unless a fact is marked uncertain, optional, or exploratory. Preserve provenance between approved starter canon, user uncertainty, generated proposals, and deferred details.

## Archive And Recovery

Default to recoverable archiving. If the project has no stronger convention, use `campaigns/_archive/<campaign-slug>/` and add an `ARCHIVE.md` recording the date, source path, reason, revival status, and unresolved canon/prep issues.

Permanent deletion always requires Ben's explicit instruction after the exact target is named. Never delete a campaign root as part of routine organization.

## Campaign Index

Create or update `campaigns/campaign_index.md` only when it helps navigation. Track title, slug, active/paused/archived status, latest session, and short notes. The index is not campaign truth.
