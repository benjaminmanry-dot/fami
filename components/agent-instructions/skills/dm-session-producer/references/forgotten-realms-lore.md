# Forgotten Realms Lore For Campaign Operations

Use this when an ongoing campaign's people, places, deities, factions, history, or monsters depend on Forgotten Realms lore. Story Engine handles lore inside its own bounded adventure production.

Prefer approved table canon, then user-provided lore, official sources, and reputable secondary references. When research is needed, cite it in working notes without copying long passages. Never let published lore silently override table canon.

Tag material as:

- `approved campaign canon`
- `user-provided Realms lore`
- `researched Realms lore`
- `proposed adaptation`
- `uncertain; verify`

Convert relevant lore into playable campaign facts: laws, obligations, routes, rumors, faction moves, NPC agendas, relic functions, and consequences. Preserve proper nouns. Note edition or era when it matters. If sources conflict, mark the conflict rather than resolving it by guess.

Keep reusable lore in campaign files only after approval. Until then, use working notes or a lore/canon docket and state what players can discover, how it changes choices, and where the claim came from.
