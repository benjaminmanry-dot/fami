# Authored operating methods

The [global guidance](global/AGENTS.md) is a public adaptation of the operating principles, with installation-specific controls and private references removed. The [loop procedure](procedures/household-loop.md) explains the general method without exporting live permissions or the household docket.

The `skills/` tree contains custom methods, scripts, templates and selected references. Personal style corpora, client rosters and raw source material are omitted. These methods require judgment and appropriate authorization; including a skill here does not make its actions permitted.

Some maintenance scripts retain their original installation layout. Inspect them as source before adapting them; running a restore/sync script can change agent instructions on a machine.

Production-specific writing and mapping methods are also in the sibling `story-engine` and `map-engine` components. Current method code is evidence of how work is attempted, not proof that all produced art or writing reached the owner's quality standard.
